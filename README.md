# Motive Elements

Motive Elements is Motive's weather experience, styled to match the Motive Labs website.

### Included
- Current weather
- City search
- Browser geolocation
- 24-hour forecast
- 7-day forecast
- Temperature unit switch
- Light/dark appearance
- Local storage for the last location and preferences
- Responsive mobile/desktop layout
- PWA manifest
- No API key required

### Data source
Weather and geocoding are provided by Open-Meteo.

### GitHub Pages
Upload these files to a repository, then enable GitHub Pages. The app is static and can be hosted directly from GitHub Pages.
